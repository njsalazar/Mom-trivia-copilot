# Mom-trivia-copilot

Copilot version

## Famous Moms Trivia Game (Millennial Edition)

A ready-to-play trivia set for a mom-themed costume party, designed for millennials (roughly born in the 1980s) with references from 90s/00s nostalgia plus current pop culture.

## How to play

1. Split guests into teams.
2. Read one clue at a time.
3. Teams guess the famous mom.
4. Award 1 point per correct answer.
5. Optional bonus: 1 extra point if a guest is dressed as that person.
